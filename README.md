# Model checking: лабораторные 1–2 (nuXmv, SPIN)

Система: турникет в метро (вариант 2). Пассажир предъявляет карту или жетон, валидатор и приёмник жетонов проверяют оплату, контроллер управляет створками и табло, фотоэлемент фиксирует проход. Среда (пассажир и безбилетник) подаёт сигналы бесконечно и недетерминированно.

| Папка | Инструмент | Модель |
|---|---|---|
| `lab1-nuxmv/` | nuXmv | `turnstile.smv`: синхронные модули, CTL + LTL |
| `lab2-spin/` | SPIN | `turnstile.pml`: асинхронные процессы, каналы, LTL |
| `reports/` | | отчёты в PDF |

## Свойства

| | Смысл | nuXmv | SPIN |
|---|---|---|---|
| P1 | после отказа створки закрыты, пока не загорится красный | true | 0 errors |
| P2 | подтверждённая оплата ⇒ пассажир пройдёт | true | 0 errors |
| P3 | открывшиеся створки открыты, пока не зафиксирован проход (`X`, `U`) | true | 0 errors |
| P4 | без оплаты пройти нельзя | **false**: «паровозик» | **1 error** |

Нетривиальность посылок: nuXmv `AG EF p`, SPIN `!([]<>p)` (найденная ошибка и есть свидетель).

## Запуск

```bash
bash lab1-nuxmv/run.sh     # nuXmv в PATH или NUXMV=...
bash lab2-spin/run.sh      # SPIN в PATH или SPIN=...; нужен gcc
```

SPIN должен быть собран с `-DNXT` (сборка по умолчанию из [nimble-code/Spin](https://github.com/nimble-code/Spin)), иначе оператор `X` в P3 не распознаётся. Пакет Ubuntu `spin` собран без него.
